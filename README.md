# PhonePe Digital Payments Analysis — Power BI Dashboard

##  Project Overview
An interactive 3-page Power BI dashboard analyzing PhonePe's 
digital payment transactions across India, built to derive 
actionable business insights from 300K+ transactions.

##  Key Metrics
| Metric | Value |
|---|---|
| Total Transactions | 300K+ |
| Total Transaction Value | ₹3.47 Billion |
| Unique Users | 108K |
| Successful Transaction Rate | 96% |
| MOM Transaction Growth | 8.97% |
| MOM Value Growth | 8.98% |

##  Features Built
- Dynamic KPI Cards with MOM Growth tracking
- Payment Status Toggle Filters — Failed / Pending / Successful
- Month-wise Slicer for time period analysis
- Age Segment Contribution — Millennials 37.3%, Gen X 37.4%
- Weekday vs Weekend Usage — 71.6% vs 28.4%
- Top 5 Users by Transaction Value
- Service-wise Transaction Analysis — Loans, Insurance, Money Transfer, Recharge Bills
- Automated Insights Card

##  Dashboard Pages
- Page 1 — Main Overview Dashboard
- Page 2 — Loan Type Analysis
- Page 3 — Age Segment Analysis

##  Tools Used
- Power BI Desktop
- DAX — CALCULATE, TOTALYTD, MOM Measures, RANKX
- Power Query — Data Cleaning and Transformation
- Data Modeling — Star Schema
